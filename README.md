# 🍽️ Saffron & Spice – Premium Indian Restaurant

A modern and elegant **restaurant website** designed to showcase the richness of Indian cuisine with a premium user experience. Built using **HTML, CSS, and JavaScript**, this project focuses on clean UI, responsiveness, and smooth navigation.

---

## ✨ Features

* 🎯 Modern & Premium UI Design
* 📱 Fully Responsive (Mobile + Desktop)
* 🧭 Smooth Navigation Bar
* 🍛 Menu Section with Food Display
* 👨‍🍳 Chef Section
* 🌆 Experience / Ambience Section
* 📞 Contact Section
* ⚡ Fast and Lightweight

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript


## 🚀 How to Run

1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in your browser
